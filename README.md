# Student Manager

A simple student management system built with **Java** as my first Java project.

## Features

- **Add Student:** Register a student with their name and grade.
- **List Students:** Display all registered students.
- **Find Student:** Search for a student by name.
- **Input Validation:** Handle invalid inputs using `try-catch` and validate grades between 0 and 10.
- **Interactive Menu:** Navigate through the available options using a console menu.

## Technologies

- Java
- Java Collections (`ArrayList`)
- Exception Handling (`try-catch`)
- Object-Oriented Programming (OOP)

## Project Structure

```text
Student-Manager/
└── src/
    ├── Main.java
    └── Student.java
```

## How to Run

1. Make sure you have the **JDK** installed.
2. Clone this repository:

   ```bash
   git clone https://github.com/viniciuscancellara-dev/Student-Manager.git
   ```

3. Open the project folder in your terminal and navigate to `src`:

   ```bash
   cd Student-Manager/src
   ```

4. Compile the Java files:

   ```bash
   javac Main.java Student.java
   ```

5. Run the program:

   ```bash
   java Main
   ```
